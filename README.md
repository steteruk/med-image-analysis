## 📊 О проекте

Система анализа медицинских изображений и классификации кожных патологий на базе алгоритмов ML/DL с использованием семейства датасетов ISIC 2018. Проект включает в себя исследование современных архитектур компьютерного зрения (Computer Vision) и создание готового к развертыванию веб-сервиса для автоматического прогнозирования по снимкам.

* **Базовый датасет:** Семейство задач [ISIC 2018 (Tasks 1, 2, 3)](https://paperswithcode.com)
